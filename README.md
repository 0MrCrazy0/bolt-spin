# Bolt Spin Slots

Virtual Hold & Spin. Entertainment only — not real-money gambling.

## Final build v73

### Features (all machines)
- Line wins — 50 paylines
- Hold & Spin — 6+ orbs and/or EXPRESS train
- Free Games — 3+ scatters (auto-play, retriggers stack)
- Machine Express — 1 EXPRESS in H&S opens themed 8-cell board
- Purple 3-match — MINI / MAJOR / GRAND trains pay global pot
- Bolt Train — rare free H&S with same 3-match rules
- Bolt Cabinet — top of lobby, play with bolt tokens
- Goals — Spins, H&S, Free Games features, Win $
